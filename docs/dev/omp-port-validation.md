# oh-my-pi 迁移本地验收记录

2026-10-08，基于 omp v18.8.4，在 macOS arm64、Bun 1.4.2 上完成本轮本地移植与复核。来源、快照与双许可边界见 [BASE.md](../../BASE.md)，接口与自动更新策略见 [base-switch-omp.md](./base-switch-omp.md)。代码仍在迁移分支工作区；本记录不表示已合并、发布或部署。

## 已完成的行为

- `qm` 命令面、独立二进制与 omp worker 重入；常驻节点按智能体和会话维护独立 RPC 子进程，保留任务投递、回执、通知、模型热切换与会话恢复。
- 扩展写入输入身份，宿主核对其实际用户条目并 fsync 后才受理和 ACK。真实 omp 在模型响应暂停时被 SIGKILL 后恢复，已受理输入未重放。
- 模型服务编译为原生配置和凭据存储；配置下发有事务恢复；实际请求验证模型、thinking、effort、鉴权和 key pool 边界。环境变量别名及混合大小写不能绕过托管凭据隔离。
- 权限规则对规范化后的真实路径执行；受保护根、软链别名与递归搜索不能借工作区授权放行。watch 的保活定时器修复已用真实 CLI 验证。
- 编程验收使用系统沙箱与宿主独立计算的结果校验，伪造测试摘要或提前 `exit(0)` 不再得到通过结果。
- 上游更新自动生成隔离候选，验证通过后建立 draft PR；合并和部署须人工审核。CI 对涉及当前或上一版基座路径的改动额外运行 omp 测试。

## 明确保留的边界

本地端点验证协议和流程，不替代商业模型质量评估。真实商业模型 AC-4、内测集群升级及长期运行、新 Linux bubblewrap 路径、GitHub 自动同步权限与 draft PR 发布链尚未在本轮实跑。旧基座的云端成绩保留为历史记录，不能计作新基座验收。

原生 key pool 按会话选钥，额度耗尽时轮换，瞬时 429 退避；旧档案选钥策略保留但不决定新节点行为。自定义 Anthropic 网关的多钥 `x-api-key` 不支持；Gemini/Grok 的 always effort 暂不支持，界面与后端均明确拒绝。

商业计划书 v7、路演 PPT v21 与宣传片 R6 的基座口径已更新。计划书 51 页、PPT 32 页正文均逐页视觉检查；PPT 保留原 14 秒片头与动画，PDF 不包含视频页。旧版材料保留，文书与宣传片仍由负责人在仓库外保存。
