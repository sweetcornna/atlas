# 阡陌 v3.0.1 GitHub Release

v3.0.1 修掉 v3.0.0 发行说明里列的两个已知问题（浏览器工具被拒、邮箱突发写入），加上握手签名与发送方绑定、对话前台改版。产品代码与 10 月 13 日部署到内测环境的产物相同（main `44a19e89`），标签所在提交只多了这篇发行说明，可以用 `git diff --stat 44a19e89 v3.0.1` 核对。发行形式与 v3.0.0 相同：`sweetcornna/atlas`，源码归档加 `SHA256SUMS`。`qm --version` 仍自报 `3.0.0-dev`，识别产物以编译进去的源码提交为准（CONTRIBUTING §11）。

## 变化

- **邮箱突发写入**（#212）：同进程的写者先按收件箱路径排队，再拿文件锁；跨进程锁等待放宽到 5 秒，超时返回带路径与预算的 `ELOCKED`。本机压测两个节点各 25 个并发任务（共 50 并发、3 轮）：修复前 66/150 完成，修复后 150/150。
- **云端电脑的浏览器与电脑工具**（#213）：节点侧参数检查接受基座给工具调用附带的意图字段，智能体调用不再被拒。
- **一台机器跑多个节点**（#211）：内测运维脚本支持任意节点名、根目录与端口；停机前核对进程命令行、节点名与配置根，PID 文件指错时拒绝发信号；非默认端口重启后保持；同机多个节点的模型服务下发共用一把主机锁。
- **控制台握手签名与发送方**（#215）：唤醒和对话的握手按目标签名——该面开了消息签名、目标公钥已用 `--trust` 固定时，用控制台密钥签并要求对端回签，节点开了 `--require-signed-handshake` 也能连上；未知公钥保持 PSK，签名失败不降级。加载了签名身份后，HTTP 唤醒与对话的 `from` 必须是控制台自己的 `--chat-from`，否则 403 `E_SENDER_MISMATCH`。
- **对话前台改版**（#214）：
  - 版式：左侧一条智能体列表（主智能体置顶、未读点、最近时间），历史会话收进顶栏，对话是气泡式，过程步骤默认折叠。
  - 状态：等待中的那一行按智能体正在做的事换成不同的小动画——思考、执行命令、读取、编辑、联网、操作电脑、操作设备、失败。
  - 形象：纯色平涂、实心眼睛、重配的十色调色板；阡陌 logo 换成最新版，用于前台、后台、登录页和站点图标。
  - 主题色：六个预设加自选色；自选色的文字颜色按对比度自动取，保证 4.5:1 以上。
  - 多语言：简体中文、English、日本語（前台全部文案；`/admin` 暂时只有中文）。
  - 管理后台 `/admin` 换用与前台相同的配色、圆角和侧栏。
- 测试与工具：demo 服务的就绪文件改为先写临时文件再改名（CI 偶发半截 JSON）；对比度浏览器用例改为按页设下限；内测运维用例判停机不再把未回收的僵尸进程当活着。

## 升级注意

- **直接调 `/v0/wake` 的脚本**：控制台开了 `--wake-sign` 或 `--chat-sign` 时，请求里的 `from` 要改成控制台的 `--chat-from`（缺省 `qianmo://console/operator`）。管理后台的唤醒表单预填的就是它，前台对话不带 `from`，都不受影响。
- **内测唤醒探针**：`demo/env/beta/ops/fleet-probe.sh install` 的 `--from` 缺省仍是 `qianmo://hub/console`，签名控制台会拒；升级已装的探针改 `ops/fleet-probe.env` 里的 `PROBE_WAKE_FROM`，新装时显式带 `--from qianmo://console/operator`（或控制台的 `--chat-from`）。
- 控制台侧没有 `--trust` 固定目标公钥时，握手仍是 PSK，启动时对每个命名目标告警一次。要给目标开签名握手：在控制台加 `--trust <节点>=<公钥>`（公钥看节点横幅），节点信任控制台公钥并开握手签名。
- **用 `demo/env/beta/beta-up.sh` 起、带见证锚点（`--anchors`）的控制台**：脚本会从锚点派生各节点的 `--trust`，所以升级后唤醒与对话握手立即变成签名双向，签名失败不回退 PSK。升级前确认各节点开了握手签名（`--sign-handshake`）并信任控制台公钥；内测环境的节点本来就是这样配的。
- 启动横幅保留 `wake-signing`；开了签名的面另有 `wake-handshake-signing`、`chat-signing`、`chat-handshake-signing`。
